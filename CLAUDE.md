# rasklad: инструкции исполнителю

Читайте AGENTS.md, SECURITY.md и текущую задачу Linear перед работой.

Claude Code реализует задачи в отдельной ветке и открывает PR. Codex независимо проверяет корректность, безопасность и критерии приёмки. Автор не объявляет собственное изменение одобренным. До выбора механизма ввода изучите docs/OPEN_SOURCE_REVIEW.md.

Работайте только в этом репозитории. Не открывайте соседние проекты, пользовательские документы, секреты и историю ввода. Не включайте системные службы, автозапуск и дополнительные права при разработке. Не запускайте код донорских проектов на рабочем столе.

Владелец разрешил облачные проверки security-guidance для rasklad. Разрешение не распространяется на приватные проекты. Не передавайте в проверку внешние каталоги, секреты и реальный ввод. Не используйте дополнительных внешних сервисов анализа кода без разрешения.

Context7 подключён как удалённый MCP. Используйте его для документации публичных библиотек, например Qt, libxkbcommon и Wayland. В запросах — только название, версия и обезличенный технический вопрос; не передавайте исходники приватных проектов, пути, ключи и пользовательский ввод.

feature-dev помогает с реализацией; frontend-design — с интерфейсом, но интерфейс остаётся Qt Quick и следует теме Omarchy. code-review — дополнительная проверка по запросу; его вывод не заменяет проверку гонок фокуса, паролей и блокировки. Комментарии в GitHub публикуйте только по явному запросу владельца.
