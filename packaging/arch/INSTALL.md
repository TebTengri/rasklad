# Rasklad для Fcitx5: установка, проверка, удаление

Пакет `rasklad-fcitx5` ставит аддон Fcitx и окно настроек:

- `/usr/lib/fcitx5/rasklad.so`
- `/usr/bin/rasklad-settings`, ярлык «Rasklad» в меню приложений (Super+Space)
  и значок;
- `/usr/share/fcitx5/addon/rasklad.conf`
- словари и модель детектора (около 5 МБ) в `/usr/share/fcitx5/rasklad/profile/`
  с их лицензиями;
- документацию и лицензию в `/usr/share/doc/rasklad-fcitx5/`,
  `/usr/share/licenses/rasklad-fcitx5/`.

Служб, автозапуска, прав, правил udev и изменений ваших настроек нет. Fcitx
подхватывает аддон при следующем запуске.

## Сборка

```
tools/build_arch_package.sh /home/mvn/Work/rasklad
```

Аргумент — каталог, где лежат проверенные файлы детектора (`build/experiment-*`).
Собирает пакет из закоммиченного HEAD в `build/arch-package/`, гоняет тесты
политики и проверку импортов. Ничего не устанавливает.

## Установка (только с разрешения владельца)

```
sudo pacman -U build/arch-package/rasklad-fcitx5-*-x86_64.pkg.tar.zst
fcitx5 -rd
```

`fcitx5 -rd` перезапускает Fcitx в фоне (заменяет запущенный).

## Как пользоваться

Работает в приложениях, включённых в Rasklad (по умолчанию Slack и Chromium).
Раскладку переключают два быстрых нажатия Alt (левого или правого) в любом
приложении; одиночный Alt и Alt с другой клавишей ничего не переключают.

- **Автоматически в конце слова** (пробел, знак препинания, Enter, Tab). Слово,
  набранное не в той раскладке, заменяется:
  `ghbdtn` → `привет`, `руддщ` → `hello`. Замена только если словарь и модель
  согласны. Короткие частые слова (`rfr` → `как`, `ns` → `ты`, `щл` → `ok`)
  исправляются по фиксированному списку. Заглавная первая буква или всё слово
  заглавными сохраняются: `Ghbdtn` → `Привет`. Слова со смешанным регистром,
  неизвестные и неоднозначные слова не трогаются.
- **Отмена.** Сразу после пробела двойной Shift возвращает набранное (и обратно).
  Работает, только если с тех пор ничего не произошло.
- **Вручную.** Пока слово подчёркнуто — двойной Shift переключает его форму; после
  этого автоматика это слово не трогает.
- Пароли, терминалы и приложения не из списка — никогда.
- Если пакет `hunspell` обновится, автоматика выключится сама (детектор сверяет
  библиотеку), а ручной жест останется; нужна пересборка пакета.
- **Настройки — приложение Rasklad** (Super+Space → Rasklad). Там включается
  и выключается исправление для каждого приложения: открытые окна появляются в
  списке сами, остальные добавляются по идентификатору окна. Терминалы включить
  нельзя: аддон отбрасывает известные терминалы, даже если их вписать в
  настройки вручную. Изменения применяются сразу, через Fcitx; тот же список
  есть в `fcitx5-configtool` → Дополнения → Rasklad.

- **Звук.** При смене раскладки (Alt+Alt, автоисправление, отмена) звучит
  короткий ретро-сигнал проекта (docs/SOUND-001). Выключается в приложении
  Rasklad.

## Ручная проверка после установки

1. Slack, тестовый канал: `ghbdtn` + пробел → `привет `; сразу двойной Shift →
   `ghbdtn `.
2. Русская раскладка: `руддщ` + пробел → `hello `; `привет` + пробел остаётся.
3. Английское слово `hello` + пробел остаётся `hello `.
4. `ghbdtn` + двойной Shift → `привет` (подчёркнуто); ещё раз → `ghbdtn`;
   пробел — вставляется показанное, без автоматики.
5. Поле пароля в Chromium: слово не подчёркивается и не меняется.
6. Терминал и любое приложение не из списка: ничего не меняется, набор как
   обычно.
7. Блокировка экрана во время набора слова: после разблокировки слово не
   переносится и не вставляется само.
8. Shift+буква, Ctrl+Shift, оба Shift — обычное поведение, не жест.

## Удаление и откат

```
sudo pacman -R rasklad-fcitx5
fcitx5 -rd
```

Настройки аддона (если вы их меняли) лежат в
`~/.config/fcitx5/conf/rasklad.conf`; удалите файл, если не нужен.

## Падение

Если Fcitx упадёт с аддоном, текущее недонабранное слово теряется. Удалите
пакет командами выше; набор вернётся к обычному.
