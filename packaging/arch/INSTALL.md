# Rasklad для Fcitx5: установка, проверка, удаление

Пакет `rasklad-fcitx5` ставит только аддон Fcitx:

- `/usr/lib/fcitx5/rasklad.so`
- `/usr/share/fcitx5/addon/rasklad.conf`
- документацию и лицензию в `/usr/share/doc/rasklad-fcitx5/`,
  `/usr/share/licenses/rasklad-fcitx5/`.

Служб, автозапуска, прав, правил udev и изменений ваших настроек нет. Fcitx
подхватывает аддон при следующем запуске.

## Сборка

```
tools/build_arch_package.sh
```

Собирает пакет из закоммиченного HEAD в `build/arch-package/`, гоняет тесты
политики и проверку импортов. Ничего не устанавливает.

## Установка (только с разрешения владельца)

```
sudo pacman -U build/arch-package/rasklad-fcitx5-0.1.0-1-x86_64.pkg.tar.zst
fcitx5 -rd
```

`fcitx5 -rd` перезапускает Fcitx в фоне (заменяет запущенный).

## Как пользоваться

- В Slack или Chromium, когда в Fcitx выбрана английская раскладка
  (`keyboard-us`): набрали слово не в той раскладке — дважды коротко нажмите
  Shift. Слово переключится на русское; ещё раз двойной Shift — обратно.
- Сразу после пробела двойной Shift заменяет последнее слово (только если его
  вставил аддон и с тех пор ничего не произошло).
- Список приложений: `fcitx5-configtool` → «Дополнения» (Addons) → Rasklad →
  Applications. Это идентификаторы окон (`slack`, `chromium`,
  `chromium-browser`).

## Ручная проверка после установки

1. Slack, тестовый канал: `ghbdtn` + двойной Shift → `привет`; ещё раз →
   `ghbdtn`; пробел — вставляется показанное.
2. `ghbdtn`, пробел, двойной Shift → `привет `.
3. Поле пароля в Chromium: слово не подчёркивается, жест ничего не делает.
4. Терминал и любое приложение не из списка: ничего не меняется, набор как
   обычно.
5. Блокировка экрана во время набора слова: после разблокировки слово не
   переносится и не вставляется само.
6. Shift+буква, Ctrl+Shift, оба Shift — обычное поведение, не жест.

## Удаление и откат

```
sudo pacman -R rasklad-fcitx5
fcitx5 -rd
```

Настройки аддона (если вы их меняли) лежат в
`~/.config/fcitx5/conf/rasklad.conf`; удалите файл, если не нужен.

## Падение

Если Fcitx упадёт с аддоном, текущее недонабранное слово теряется. Удалите
пакет командами выше; набор вернётся к обычному.
