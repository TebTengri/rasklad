# Данные первого локального эксперимента

Статус допуска: **approved-local-experiment**, не разрешение на выпуск словаря или обученных weights в составе приложения.

Используется один фиксированный снимок LibreOffice/dictionaries: commit указан в sources.json. Выбраны ru_RU/ru_RU.dic и en/en_US.dic; первичные README с полными copyright/source notices сохранены без изменений в notices/. Источники прочитаны до загрузки данных; авторы и условия описаны в этих документах, не заменены одной общей лицензией репозитория.

## Разрешённый эксперимент

- Локальные фильтрация, обучение числовых n-gram таблиц, калибровка и оценка.
- Сохранение исходных файлов и производных артефактов только в игнорируемом build/experiment-data/ и других каталогах build/.
- Полные notices рядом с локальными копиями; преобразования явно помечены как модификации rasklad. Имена авторов не используются для продвижения.
- Перед выпуском данных/weights нужна отдельная проверка исходных условий, notices, воспроизводимости и области лицензии каждого артефакта. В этом PR нет corpus/weights, только паспорта, notices и код стенда.

Русский README допускает распространение с сохранением уведомлений и пометкой модификаций. Английский README описывает SCOWL и составные источники (включая WordNet, VarCon, Ispell и другие) с собственными уведомлениями. Полные условия сохранены для проверки. Английский README сообщает версию словаря 2020.12.07; версия общего репозитория и словарной базы не тождественны.

## Что этот набор не доказывает

В .dic находятся словарные записи с affix flags, а не естественная частотная речь. Стенд удаляет flags и не разворачивает словоформы; каждое отобранное написание имеет одинаковый вес. Lowercase/letter-only фильтрация меняет распределение и не охватывает реальные имена, код и текстовые поля.

Train/calibration/test из этого набора — словарная проверка по типам. Prefix grouping снижает часть родственных пересечений, но не является полным разбиением по леммам. Независимый естественный test-корпус ещё не допущен; результаты нельзя объявлять качеством на пользовательском наборе.

## Получение и контроль

sources.json содержит commit, конкретные URL, SHA-256 файлов данных и notices, размер, операции и ограничения. Загрузка — отдельное явное действие подготовки эксперимента. Сборка, модульные тесты и inference не скачивают данные. Если локальные файлы отсутствуют или hash не совпал, эксперимент не должен продолжаться с неподтверждённой заменой.

См. [DATA_POLICY](../docs/DATA_POLICY.md). Проверил Codex, 2026-11-10. Это технический допуск указанного локального использования по прочитанным первичным условиям; юридически спорные случаи и выпуск производных моделей сюда не входят.
