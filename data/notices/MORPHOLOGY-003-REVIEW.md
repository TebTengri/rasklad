# Морфологический контроль: допуск локального опыта 003

Проверил Codex, 2026-11-11, до получения affix-файлов. Версия LibreOffice/dictionaries c0865a85eb67dc377f2cf8e8fe2c4fa9e53f0dcb. Два уже проверенных raw .dic остаются неизменными, включая flags и регистр. Дополнительно проверяются en/en_US.aff и ru_RU/ru_RU.aff.

Первичные условия:
- en/README_en_US.txt, раздел COPYRIGHT/SOURCES/CREDITS прямо относит affix-файл к модифицированному english.aff из Ispell под BSD-условиями Geoff Kuenning; полный Ispell notice присутствует в ранее сохранённом en_US.README.txt. Это конкретное указание для en_US.aff, не перенос общей лицензии каталога по умолчанию.
- ru_RU/README_ru_RU.txt прямо описывает модификацию ru_RU.aff; разрешает использование/модификацию/распространение при сохранении notices, пометке модификаций и без endorsement. Полный notice сохранён ранее.
- https://raw.githubusercontent.com/hunspell/hunspell/v1.7.5/README.md и установленные заголовки указывают альтернативы MPL1.1/GPL2+/LGPL2.1+ и происхождение MySpell. Для локального использования неизменённой системной shared library рассматривается MPL1.1; дополнительно сохраняется MySpell BSD notice. Полные тексты COPYING.MPL и license.myspell сохранены рядом. Библиотека уже установлена, не скачивается и не распространяется нашим репозиторием.

Допуск только local experiment: чтение/проверка spell в API и детерминированное удаление строк PFX/SFX для контрольного affix-файла. Другие директивы, регистр, compounding, NEEDAFFIX и т.п. сохраняются; этот контроль нельзя называть полностью лишённым морфологии. Это модифицированная производная, notices и пометка преобразования хранятся рядом с файлами в build/experiment-003-data. .dic не фильтруется и не переписывается.

Не включать source data, производные словари или бинарную библиотеку в Git/дистрибутив. release_approved=false; для выпуска отдельно разобрать source/executable obligations выбранной альтернативы, все компоненты и фактическую упаковку. Этот технический допуск локального сравнения не является универсальным юридическим заключением. Новый корпус не загружается: новая непересекающаяся по ID/текстам часть прежнего допущенного CC0 snapshot, прежние ограничения действуют.

Первичные URL словарных условий и точные hashes: data/sources.json. Первичные Hunspell notices: https://raw.githubusercontent.com/hunspell/hunspell/v1.7.5/COPYING.MPL и https://raw.githubusercontent.com/hunspell/hunspell/v1.7.5/license.myspell . Код чужих проектов в нашу реализацию не переносится, используется установленный C API spell.
