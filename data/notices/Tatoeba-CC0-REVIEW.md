# Tatoeba CC0: допуск только локальной оценки, опыт 002

Проверил Codex, 2026-11-11, до скачивания текстов. Издатель: Tatoeba Association; авторы — участники, выбравшие CC0 для собственных оригинальных предложений. Используются только отдельные официальные *_sentences_CC0.tsv.bz2; общие выгрузки с CC BY не допускаются этим паспортом. Поля — ID, ISO language, текст; профили/имена участников, комментарии, аудио и переводы не загружаются.

Первичные источники:
- https://en.wiki.tatoeba.org/articles/show/cc0-contributions — CC0 опционален; применяется к собственным оригинальным предложениям, не к переводам чужих текстов.
- https://tatoeba.org/en/terms_of_use — авторские права и ответственность участников; §6 и §8.2.
- https://downloads.tatoeba.org/exports/per_language/eng/ — отдельная sentence-only CC0 выгрузка.
- https://downloads.tatoeba.org/exports/per_language/rus/ — отдельная sentence-only CC0 выгрузка.
- https://creativecommons.org/publicdomain/zero/1.0/legalcode.txt — полный CC0 1.0 Universal; копия CC0-1.0.txt рядом.

Технический допуск: локальное чтение, декомпрессия, детерминированная выборка, токенизация и evaluation с агрегированными результатами. Не использовать для train/calibration/подбора порогов этого опыта. Copyright waiver/fallback не подтверждает отсутствие чужих прав и персональных сведений; publisher не гарантирует правильность всех предложений. Это не юридическая гарантия и не разрешение выпускать любой текст или производные модели.

Корпус и его преобразованные копии только в игнорируемом build/experiment-002-data/. Сохранять первичные ссылки, snapshot date, SHA-256 compressed/decompressed файлов и этот review рядом с локальными копиями; преобразования явно обозначать. Не публиковать предложения, sentence IDs, имена или списки неудачных примеров. В Git — паспорт/CC0/review и проверенные агрегаты без слов/весов. release_approved=false; no training. Авторов не использовать для endorsement.

Ограничения: отдельный источник относительно LibreOffice, но пересечение написаний ожидаемо и измеряется. Tatoeba — добровольные языковые примеры, не частотный корпус обычного ввода. CC0 subset может иметь сильный перекос по авторам/темам и повторяющиеся конструкции; correctness/language labels шумны. Sample rule/seed зафиксированы до получения текстов; частоты и CI нельзя переносить на пользователя. Рассмотренный UD-PUD не выбран: первичный README ссылается на exceptions/implied rights для исходного текста; для этого опыта предпочли отдельную CC0 цепочку, не объявляя иной набор незаконным.
