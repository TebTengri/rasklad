# Проверка первой версии ядра

Задача SYS-224, дата 2026-11-10. Исполнитель — Claude Code; независимая проверка — Codex.

## Что проверено

- Codex прочитал исходники, qmake-проекты и сборочные скрипты до запуска.
- `bin/test -silent` собрал Qt Core static library и Qt Test binary: 160 passed, 0 failed, 0 skipped. Qt 6.12.0, C++17, qmake6/make/g++.
- Независимый временный harness сравнил результат с libxkbcommon 1.13.2, скомпилировав XKB us/ru для evdev/pc105, без подключения к дисплею и устройствам. Все 94 пары ANSI key/level совпали в обоих направлениях.
- Тот же harness проверил все 65536 одиночных UTF-16 code units в каждом направлении (131072 проверки) против карты, полученной из XKB: совпадение. Это проверка одиночных code units, не всех возможных Unicode-строк.
- Qt Test отдельно покрывает combining marks, emoji, смешанные строки, регистр, пунктуацию и неправильное значение направления.
- `bash -n bin/build bin/test` и `git diff --check` завершились успешно.

Независимый harness использовался как разовая дополнительная проверка и не включён в обязательные зависимости проекта. Регулярный набор `bin/test` требует только Qt Core/Test и компилятор.

## Замечания ревью

Уточнено описание явного направления вызова и ограничений источника символов. По QString нельзя отличить одинаковый символ от основной клавиатуры, AltGr или keypad; обещание сохранить все символы неподдерживаемого происхождения было бы неверным. Контракт ограничен стандартными us(basic)/ru(default) и описан в README.

## Что не проверено и не реализовано

Нет GUI, CLI для пользовательского ввода, глобальных клавиш, обработки устройств, автоматического определения языка, установки или службы. Исправление текста в других приложениях и безопасность password/lock/focus не проверялись: backend не запускался. SYS-223 остаётся открытой; гипотеза backend находится в ADR-001-input-boundary.md.

Эта проверка не является полным аудитом зависимостей Qt, анализом всех возможных строк или гарантией отсутствия ошибок. Не выполнялись сетевые и системные действия от имени ядра.
