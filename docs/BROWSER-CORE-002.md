# SYS-242 — общая таблица решений из нативного ядра

2026-11-13. Продолжение browser adapter 001, ветка SYS-242/message-adapter.

## Решение

Политика SafeConfirmed/RequestedHybrid зависит от шести булевых признаков
словарной принадлежности, одного действия модели и профиля. Это конечные
512 состояний (64 × 4 × 2, включая недопустимое действие модели). Нет причины
переписывать эту политику вручную на JavaScript или устанавливать WASM SDK
только ради неё.

Developer exporter собирается через установленный qmake6/make, вызывает настоящий
`DecisionRouter::route` для каждого состояния и дедуплицирует ответы action/reason.
Допустимые US/RU символы и их канонические индексы получаются непосредственным
вызовом `canonicalizeToken` по BMP. Преобразование использует прежний общий
источник собственных 94 пар. Исходники ядра не изменены.

Браузерная обвязка выполняет проверки контекста/длины/канонических символов,
валидирует синхронную evidence и выбирает ответ из экспортированной таблицы.
`Suggest` никогда не применяется автоматически. Конвертация вызывается только
для Correct/Suggest. Runtime не запускает Qt-процессы, не открывает IPC/сеть,
не читает filesystem и не передаёт слова наружу.

Генерируемые policy.js и converter.js находятся только в build/. Сборка сохраняет
SHA-256 собственных исходников ядра в provenance.json. Это воспроизводимость
developer build, не криптографическая защита от подмены артефакта локальным
процессом. Защита будущего дистрибутива требует отдельного packaging/signing.

## Граница результата

Это общее исполняемое правило решений, **не порт полного n-gram scorer или
Hunspell в браузер**. Native C++ exporter не открывает модель/словари/корпус.
Fixture evidence синтетическая; реальная точность и цена полного детектора не
измеряются здесь. Доступ к старым реальным артефактам не возобновлялся.

Ограничения адаптера 001 сохраняются: собственный plain textarea, US→RU,
непроверенные rich editors/contenteditable/почтовые приложения, deprecated
execCommand. Никаких установок, host profile, изменений системных клавиш и
эксклюзивного ввода. Двойной Super остаётся пользовательским ручным действием;
его доставка владельцу поля и OS layout bridge не реализованы этим изменением.

## Проверки

Нативные DecisionTests: 31 passed, включая существующий паритет с frozen research
policy; синтетические данные, без реального профиля. Экспорт: 66 допустимых
символов на раскладку, 512 состояний, 9 уникальных ответов; JSON metadata 2 578
байт в первоначальном прогоне. Это не размер всей программы.

Claude Opus 5.5 реализовал browser/router.js и его тесты по публичному заданию
в safe/no-tools режиме. Codex независимо проверил порядок gates, индексацию
таблицы, строгие типы evidence, границы и отсутствие текстового I/O, подготовил
C++ exporter и подключение к adapter. Подмена policy после factory не меняет
приватный snapshot; invalid/Promise/throwing provider fail closed.

Node: 12 router tests, включая все 512 строк и gates до чтения token, strict bools,
исключения/Promise, bounds/Unicode, RU reverse, запрет auto Suggest и snapshot
policy. Прежние 13 adapter/converter tests прошли. Browser fixture использует
реальный table lookup при default correction; evidence по-прежнему синтетическая.

Итоговый browser прогон общего пути: 30 assertions passed, включая отказ
ambiguity/dictionary-only и запрет автоматического Suggest. Медианы Space
baseline/adapter ниже разрешения ~0,1 мс; p95/max около 0,1 мс в коротком
прогоне 50/50. JS heap всей страницы 936 400 байт. Это не overhead/RSS и не замер
реального scorer. Результат не доказывает отсутствие задержек на других машинах.

Generated policy.js 2 951 B, converter.js 1 904 B, browser/router.js 8 542 B:
13 397 B для этих трёх файлов без сжатия. Это не весь адаптер/дистрибутив; реальные
модель и словари не включены. Новый runtime dependency или WASM SDK не установлен.
