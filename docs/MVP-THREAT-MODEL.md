# Модель угроз manual-preview MVP (SYS-239)

Это требования и границы проверки собственного окна, а не аудит всей ОС.
Алгоритм и профиль данных закреплены в [ADR](ADR-001-DETECTOR-ROUTING.md).

## Что защищаем

Текст документа, содержимое clipboard, целостность исходного текста и возможность
отменить последнюю явную замену. Приложение получает только текст, который человек
сам ввёл или вставил в его окно. Фокус чужого приложения не разрешает читать ввод.

## Границы доверия

- UI передаёт текст контроллеру; контроллер ограничивает объём и хранит только
  текущий документ, текущий preview и одну доступную отмену в памяти. Apply и массовая правка заменяют эту запись; одиночный ввод её сбрасывает.
- Чистое ядро возвращает решение и причину. Оно не применяет изменения и не
  выполняет I/O. Решение Correct само по себе не является разрешением на замену.
- Worker владеет локальным provider. Результат связан с версией документа,
  направлением и поколением профиля; устаревший результат не применим.
- Профиль подключается явно. Пути, размеры, хеши и происхождение данных проверяются
  до использования. Ошибка отключает анализ, сохраняя ручное преобразование.
- Clipboard — внешний получатель текста: запись допустима только по явной команде
  Copy. Фоновое чтение, наблюдение и синхронизация не входят в приложение.

## Сценарии, которые должны проверяться

| Сценарий | Требуемое поведение |
| --- | --- |
| Текст изменён после preview или во время анализа | Старый результат не заменяет новый текст |
| Направление либо профиль изменены во время анализа | Старый ответ отброшен |
| После Apply человек снова печатает | Старая Undo не затирает новую редакцию |
| Unknown/protected context поступил в будущий adapter | Не запрашивать provider, не накапливать скрытый текст |
| HTML, QML, команды оболочки, emoji в документе | Только plain text; ничего не исполняется |
| Вход превышает лимит | Явный отказ без незаметного усечения документа |
| Файл профиля отсутствует, повреждён, подменён symlink | Анализ недоступен; без скачивания или ослабления правил |
| Закрытие во время работы worker | Завершение владельца provider без обращения к уничтоженным объектам |

## Ограничения защиты

Проверка SHA-256 обнаруживает отличие от закреплённых файлов; это не sandbox
Hunspell и не защита от вредоносного динамического загрузчика. Процесс с тем же
UID, root, скомпрометированный compositor, отладчик или clipboard manager находятся
вне этой модели. Очистка QString не гарантирует криптографического стирания копий
из памяти, swap или core dump. В окно не следует помещать секреты ради испытаний.

Глобальные hooks, uinput, системные разрешения, фоновые службы, автозапуск,
телеметрия, обучение на вводе и выпуск словарей не разрешены этим MVP. Каждый такой
этап требует собственного контракта, оценки и проверки; SYS-223 остаётся отдельной
задачей по безопасному механизму ввода.
