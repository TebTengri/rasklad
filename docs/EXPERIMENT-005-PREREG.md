# Предрегистрация 005: контекст и совпадающие наблюдения

SYS-237, 2026-11-11. [Полный протокол](../data/experiment-005-protocol.json) фиксируется до генерации новых случаев и расчёта решений. Это синтетическая проверка механизма и ограничений информации, не новый natural corpus и не оценка качества чата. Никакая модель не обучается; scorer/словари/пороги прежние. Политику пишет Claude, данные/labels и независимую сверку — Codex.

Пул неоднозначности — все общие stem keys EN/RU длиной2..32. Разбиение по hash keygroup на development/holdout; анкоры префиксов в них разные. Это защищает от прямого повторения примеров, но не делает шаблоны естественной речью или независимыми испытаниями. Дополнительно отбираются unambiguous контролы только по словарному membership, без фильтрации по решениям модели.

Одинаковый target/layout с префиксом своего языка получает Keep-intent; с противоположным — Correct-intent. Отдельно намеренное заимствование получает EXACT SAME observable prefix+target, но Keep-intent. Любая детерминированная политика видит одно и то же и не может одновременно исправить первый случай и сохранить второй. Эта collision-пара — контроль идентифицируемости намерения, а не два естественных предложения с надёжно различимой семантикой.

Простейший context vote использует только script двух предыдущих native-letter-only слов длиной4..32; смешанный/пустой контекст не даёт решения. Семантического понимания нет. Новые context методы допускают target2..32; старые token методы сохраняют guard>=4. Для честного сравнения публикуются short/long группы отдельно. Известное protected поле → Keep, unknown → Abstain; это oracle metadata, не реализация безопасного системного поля.

Шесть политик: alwaysKeep, прежние model/full, contextAuto, guardedContextAuto (veto общей dictionary ambiguity), contextSuggest (альтернатива предлагается без замены). Gold labels и scenario IDs — в отдельном файле, политика их не получает. Все derived слова/префиксы/features/labels/actions только ignored build/. Из словарей берутся производные данные по прежнему local-only допуску с полными notices; собственные короткие шаблоны не объявляются автоматически свободным естественным корпусом. Новый внешний набор не скачивается, выпуск не одобрен.

Бюджеты теперь раздельны: ноль automatic changes на prose Keep, protected, unknown и ambiguous Keep; минимум50% auto recovery ambiguous Correct и unambiguous control Correct для каждой typed layout и pooled holdout. Suggest не считается автоматическим исправлением. Нулевой знаменатель → insufficient. Collision invariant recovery+preservation<=1 публикуется для каждого метода. Никакого выбора исключений/порогов после holdout. Ожидаемый структурный конфликт бюджета обсуждается прямо, не выдаётся за экспериментальное доказательство бесполезности контекстных моделей.

C1 — неизменность token-only решений и ceiling collision; C2 — покрытие простого script-context с обязательным учётом ошибок borrow Keep; C3 — цена ambiguity veto; C4 — предложения отдельно от действий; C5 — все части budget без подмены суммарной точностью. Ни один исход не включает системный ввод, сбор истории, установку или auto-deployment. Новый естественный holdout понадобится до любых заявлений о качестве нового контекстного признака вне этих шаблонов.
