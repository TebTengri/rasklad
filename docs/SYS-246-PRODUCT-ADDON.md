# SYS-246: рабочий аддон с ручным двойным Shift

Статус: проект (2026-11-21). Кода установки на хост нет; установка — SYS-228
и отдельное разрешение владельца.

## Решения владельца

- Жест — двойной Shift (SYS-225), тройного нет.
- Включено только в разрешённых приложениях, остальное выключено.
- Первая версия: Slack и Chromium (`slack`, `chromium`, `chromium-browser`).
- Список меняется в настройках Fcitx.

## Что такое «приложение»

Fcitx 5.1.23 на Hyprland узнаёт `app_id` активного окна через
foreign-toplevel (AppMonitor) и отдаёт его как `InputContext::program()`.
Измерено: Slack — `slack`, Chromium — `chromium` / `chromium-browser`.

Это заявление композитора, не аутентификация: любое локальное приложение может
назвать окно `slack`. Поэтому вводится отдельный уровень
`Identity::CompositorAppId`, и он допускает только **ручной** режим (жест
пользователя на одно слово), никогда автоматический.

## Политика (`src/applicationpolicy`)

- `Mode::ManualDoubleSuper` → `Mode::Manual` (жест — двойной Shift).
- `Adapter` получает флаг `manual`.
- `authorizeCapture` для `Mode::Manual`:
  - запись `RegularApplication` с `manual = true`;
  - identity `CompositorAppId` или `VerifiedAdapter`;
  - поле `Prose` или `Unknown` (Fcitx не знает, проза ли это); `Password`,
    `Protected` и остальные — отказ;
  - фокус, id и epoch контекста — как сейчас.
- `Mode::Automatic` без изменений: только `VerifiedAdapter` + `Prose`.

## Аддон

Файл `src/raskladproduct.cpp`, сборка `tools/fcitx_product.pro` с флагом `RASKLAD_PRODUCT`.
Он сохраняет проверенную логику: пары нажатий и отпусканий, эпохи, сброс по событиям,
подтверждение своего слова после пробела.

До SYS-255 продукт собирался из `src/fcitxlab.cpp` вместе с лабораторными вариантами.
Теперь он выделен в свой файл механически: для флагов продукта препроцессор даёт тот же
код, что и раньше. Общие правила — в `src/configrules.h` и `src/wordrules.h`.
`src/fcitxlab.cpp` хранит только лабораторные варианты и заморожен.

- Нет переменных окружения стенда, квитанций, канала надзора, D-Bus, профиля.
  `#error` запрещает смешивать с лабораторными вариантами.
- Список приложений — конфигурация аддона Fcitx (`Applications`, по умолчанию
  три идентификатора выше), читается при загрузке и `reloadConfig`; вне списка
  состояние не создаётся.
- Метод ввода — `keyboard-us`; при другом аддон ничего не делает.
- Отказ всегда: `Password`, `Sensitive`, `NoSpellCheck`, `Terminal`,
  `Disable`, нет `Preedit`.
- Поведение — как в закрытых прогонах SYS-225 (26/26 Hyprland).

## Известные ограничения v1

- Направление только us→ru (набрано в английской раскладке). Обратное — позже.
- Слово набирается в preedit (подчёркнуто) до пробела.
- `app_id` можно подделать локально; последствие — ручной жест в чужом окне,
  а не автоматическая правка.

## Реализация и офлайн-проверки (2026-11-21)

- Политика: `Mode::Manual`, `Identity::CompositorAppId`, `Adapter::manual`;
  тесты политики 90, разрешений 57 (включая ручной режим).
- Аддон: `tools/fcitx_product.pro` → `build/product-addon/rasklad.so`,
  дескриптор `addon/rasklad.conf`. Импорты без `getenv`, D-Bus, сокетов,
  запуска процессов; экспорт — только фабрика.
- Поле из флагов Fcitx (`fieldFromCaps`); список приложений проверяется по тем
  же правилам, что реестр; изменение настроек сбрасывает все композиции.
- Закрытый Sway: рабочий аддон, приложение в списке — 26/26
  (`data/product-addon-sway-listed-001-result.json`); не в списке — 3/3,
  ничего не перехвачено (`data/product-addon-sway-unlisted-001-result.json`).
- Лабораторные сборки после правок: Sway 26/26, модульные тесты аддона,
  отключения и композиции — OK.
- Grok (FIX-FIRST) — исправлено: хранилище разрешений сбрасывается до
  перестройки списка; изменение настроек применяется всегда; вложенное
  применение во время сброса композиций игнорируется. Не меняли: путь
  отключения (Off) с ручным режимом отказывает безопасно и в рабочей сборке не
  используется; поле без флагов считается Unknown и допускается только ручным
  жестом — известный остаточный риск, если приложение не помечает поле пароля.
  Повтор Sway: 26/26 и 3/3.
