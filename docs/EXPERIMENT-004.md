SYS-236, 2026-11-11. [Предрегистрация](EXPERIMENT-004-PREREG.md), [протокол](../data/experiment-004-protocol.json), [команды и ограничения](EXPERIMENT-004-METHOD.md), [агрегаты](results/experiment-004.json), [независимая сверка](results/experiment-004-audit.json), [проверки](results/experiment-004-validation.json).

На этом техническом жанре **полный морфологический словарь дал больше полезных исправлений, чем связка с подтверждающей моделью**: 23 603 восстановления против 22 682 при нуле наблюдавшихся небезопасных действий у обоих. Confirmation потерял 921 исправление без измеримого выигрыша безопасности. Fallback добавил 400 восстановлений, но сделал 29 ложных замен. Выигрыш confirmation из опыта003 здесь не воспроизвёлся. Это новый результат, не подбор нового порога.

Разметка fenced/inline code известна оценщику. Защищённые варианты принудительно Keep в таких spans, остальная проза побитово совпадает с базовой политикой. Это oracle-контекст, не готовый механизм определения безопасного системного поля. Parser ограничен source Markdown: не выполняет mdBook includes, HTML, ссылки и код; не загружает внешние code samples. Часть технического кода книги поэтому не представлена как отрисованные примеры.

## Заранее объявленные гипотезы

**D1 — inconclusive: выигрыш confirmation не продемонстрирован.** Full и confirmed-full имеют0 unsafe вхождений/типов. Подтверждение не могло уменьшить уже нулевое наблюдавшееся число; потеряло921 recovery (212 типов), из них150 EN и771 RU. Это не опровержение возможности защитного эффекта на других жанрах, но дополнительная консервативность здесь не дала измеримого выигрыша. Не переносим вывод003 «5→0» как универсальную гарантию.

**D2 — поддержана как прибавка покрытия с ценой.** Fallback добавил400 recoveries (108 типов) без потерь, но добавил29 unsafe действий (8 типов):27 code+2 prose. После code gate остаются2 prose ошибки (один тип). «Модель на неизвестных словах» не даёт бесплатного автоматического покрытия.

**D3 — поддержана для model/fallback, inconclusive для full/confirmation.** Oracle code gate предотвратил27 изменений модели/fallback (7 типов), сохранил все prose действия и wrong recoveries. У full/confirmation исходных code changes не было, поэтому выигрыш от gate на этой выборке не показан. Предотвращение измерено на known labelled spans; доступность такого контекста в клавиатурной интеграции не проверялась.

**D4 — все зафиксированные screen verdicts опубликованы.** Требования: <=1 false на10 000 eligible prose occurrences И types, отдельно EN/RU/pooled; ноль code changes; >=50% eligible unambiguous wrong recovery. Full и confirmation проходят на обоих языках с gate и без; это две базовые политики, а не четыре независимых успеха. AlwaysKeep проваливает recovery-часть. Model/fallback без gate проваливают code-часть; с gate проходят EN, но не RU/pooled.

На pooled prose модель/fallback дают0,823 false на10 000 eligible вхождений (формально в бюджете), но1,834 на10 000 типов (вне бюджета). RU:1,946 по вхождениям и3,034 по типам; EN0. Усреднение по документам RU даёт0,739: оно скрывает концентрацию ошибок в одном документе, поэтому macro-rate не заменяет все первичные счётчики.

**Ограничение самого screen:** в зафиксированном правиле нет отдельного лимита для ambiguous wrong. Поэтому protectedTwoScore формально проходит EN screen, несмотря на29 unsafe ambiguous wrong действий в EN. Протокол после результата не переписываем. Для следующего опыта нужен отдельный предварительный бюджет этих действий. Прохождение screen не тождественно отсутствию всех рисков — это подтверждено самим опытом.

## Ограничения переноса и редких ошибок

Это один новый жанр — programming textbook, не чат, имена/никнеймы, команды живого терминала или повседневная переписка. EN/RU переводные и тематически коррелируют, хотя exact source document duplicates0. С Tatoeba002/003 пересекаются1650 из2957 EN prose exact types (55,8%) и1675 из3890 RU (43,1%); по вхождениям21 822/25 695 EN и10 612/15 388 RU. Новый документный домен не означает новый словарь целиком. Overlap только диагностический, слова не исключались и решения не менялись.

Нулевая ошибка словаря — наблюдение на ограниченной коррелированной выборке. Оно не сертифицирует частоту <=1/10 000, особенно по5453 pooled eligible типам. Повторяющиеся слова не независимы, IID доверительные интервалы не строим. Бюджет — эмпирический инженерный screen; deployment precision не оценивается из искусственной доли wrong. Границы токенов/typed layout известны оценщику; сквозной ввод и безопасные поля не проверены.

## Решение

Полный морфологический словарь остаётся сильным baseline. Не включаем обязательное подтверждение моделью только по опыту003: на новом жанре оно потеряло покрытие без наблюдаемой пользы. Fallback модели рассматриваем прежде всего для предложений с подтверждением человеком; безопасная автоматическая прибавка пока не показана.

Следующий исследовательский шаг — контекстная неоднозначность и adversarial минимальные пары с раздельным бюджетом prose/code/ambiguous wrong; отдельный новый holdout до любых новых правил. Проверить, какой контекст действительно меняет решение, прежде чем добавлять нейросеть или персонализацию. Этот технический блок теперь диагностический. Системный auto-input остаётся вне опыта.
