# SYS-242 — собственное браузерное поле, первый срез

2026-11-13. Ветка SYS-242/message-adapter от main 849267c.

Реализован owner-side адаптер, не глобальный перехватчик. Обычные символы сразу
записаны в документ; на пробеле доверенный владелец поля заменяет диапазон,
проверяя фокус/состояние до и после синхронного evidence. Неудавшийся no-op
оставляет исходный Space; неожиданный результат отключает адаптер без rollback.
Существующие runtime Qt, системные настройки и реальные данные не затронуты.

Результаты на Chromium 155.0.8059.84 в закрытом bwrap:

- 28 browser assertions: буквы до пробела; замена; native Ctrl+Z; следующий символ;
  исключение unknown/code/password form, URL/path; abstain; смена контекста и
  снимка во время evidence; отклонение Promise; composition/untrusted/selection;
  dispose; ложный/исключительный no-op; изменение страницы во время input; отмена с последующим Space; парольный control
  вне form; отказ после выделения/следующая буква; защита после native input
  без повторного чтения value;
  превышение лимита; целостность двух 50-word измерительных серий.
- 13 Node tests: исключённые поля не читают value и не запрашивают evidence;
  освобождение listeners, отказ неподдерживаемых ролей; map/Shift/Unicode marks;
  roundtrip всех 94 printable ASCII символов.
- Замер 50 Space на условие: baseline и adapter median 0 мс, p95 около 0,1 мс,
  max около 0,1 мс при дискретности performance.now около 0,1 мс. Это не «нулевая
  задержка»: различие ниже разрешения данного короткого замера. Измеряется
  обработка beforeinput до microtask, не физическая клавиатура/отрисовка.
- JS heap всей страницы после проверок: 832 028 байт в одном прогоне. Это не RSS
  браузера и не дополнительная память адаптера. Данные не доказывают малую нагрузку
  полного продукта: реальный detector/model здесь отсутствует.

Общий источник converter — существующая собственная таблица C++; generator
проверяет размер/инъективность. Общий DecisionRouter ещё не перенесён в browser
runtime. Synthetic evidence только для механики, качество языка не измерялось.
Сторонний код/данные не добавлены; библиотек npm и сетевых загрузок нет.

Claude Opus был вызван в согласованном safe/no-tools режиме с публичным заданием,
но первый запрос завершился HTTP 403 Cloudflare; реализацию подготовил Codex.
Повторный запрос независимого ревью прошёл (claude-opus-5-5). Claude нашёл
незакрытый selection при отказе, повторное чтение после смены protected hints,
неучтённые внешние form-associated credential controls и повторную автозамену
после Undo. Исправлены cleanup диапазона на всех выходах, post-edit gate,
проверка form.elements и подавление одного Space после historyUndo/Redo без
сохранения слова. Браузерные регрессии добавлены. Замечания о shadow DOM,
пунктуационных словах и других движках оставлены явными ограничениями,
не объявлены поддержанными. Ревью не является независимым запуском тестов.

Полные границы, запуск и следующий шаг: [browser/README](../browser/README.md).

расширения, ручной двойной Super и terminal milestone ещё не закрыты.
