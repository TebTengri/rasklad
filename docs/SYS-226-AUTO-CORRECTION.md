# SYS-226: автоматическое исправление раскладки в аддоне Fcitx

Состояние на 2026-11-22: работает у владельца на хосте, пакет `rasklad-fcitx5`
0.3.1 (PR #23, #24, #25; до этого SYS-246 #21 и SYS-228 #22).

## Что делает

- **Исправление в конце слова** — пробел, знак препинания, Enter, Tab. Слово,
  набранное не в той раскладке, заменяется в обе стороны: `ghbdtn` → `привет`,
  `руддщ` → `hello`.
- **Решение** — проверенный профиль safeConfirmed (ADR-001: полный словарь
  Hunspell + n-gram модель, зафиксированные пороги). Плюс фиксированный список
  частых коротких слов (`src/frequentwords.h`), где роутер по замыслу
  воздерживается (меньше 4 букв). Из списка исключены слова, у которых набор
  совпадает со словом другого языка: мы/`vs`, где/`ult`, еще/`tot`, за/`pf`,
  ну/`ye`, ли/`kb`; the/`еру`, in/`шт`, if/`ша`, but/`иге`, her/`рук`,
  here/`руку`.
- **Регистр** — заглавная первая буква или всё слово заглавными сохраняются.
  Смешанный регистр не исправляется.
- **Знаки в конце слова** — `,` `.` `;` и т. п. в конце английского набора
  остаются знаками, если слово целиком не исправилось: `ghbdtn,` → `привет,`.
- **Отмена** — двойной Shift сразу после пробела возвращает набранное. Слово,
  переключённое жестом до пробела, автоматика не трогает.
- **Переключение раскладки** (решение владельца) — после исправления или отмены
  текущим методом ввода Fcitx становится раскладка исправленного слова
  (keyboard-us ↔ keyboard-ru). Переключение отложено до пустого слова. Нужны обе
  раскладки в группе Fcitx.
- **Звук** — при каждой смене us/ru звучит собственный ретро-сигнал проекта
  (SOUND-001). Синтез совпадает с исходным WAV сэмпл в сэмпл. Сигнал играет
  через ALSA в коротком потоке, с ограничением по времени. Опция `Sound`.
- **Границы** — только приложения из списка владельца (`Applications`,
  по умолчанию `slack`, `chromium`, `chromium-browser`). Решение владельца от
  2026-11-21: для автоматики достаточно идентификатора окна. Пароли,
  чувствительные поля, терминалы и приложения не из списка не трогаются никогда.

## Профиль и пакет

Профиль (словари, модель, лицензии; около 5 МБ) лежит в
`/usr/share/fcitx5/rasklad/profile` и сверяется с зашитыми sha256. Если файлы
или библиотека Hunspell изменились, автоматика выключается, а жест остаётся.
Тогда нужна пересборка пакета. Сборка:
`tools/build_arch_package.sh <каталог с build/experiment-*>`. Словари допущены
только для локальной установки; публичный выпуск не проверялся.

## Настройка хоста владельца (2026-11-22, по просьбе владельца)

- **Fcitx.** Группа `Default` состоит из `keyboard-us` и `keyboard-ru`
  (через D-Bus `SetInputMethodGroupInfo`). Горячие клавиши `EnumerateForwardKeys`
  (`Alt+Alt_R`, `Alt+Alt_L`) срабатывали от одиночного Alt; 2026-11-22 убраны
  (D-Bus `SetConfig fcitx://config/global`, копия `config.bak.1795296359`).
  Раскладку переключает аддон: два быстрых нажатия Alt (решение владельца).
- **Панель Omarchy.** На месте `omarchy.keyboard-layout` стоит свой виджет
  `rasklad.layout`: `~/.config/omarchy/plugins/rasklad.layout` — символическая
  ссылка на `/usr/share/rasklad-fcitx5/omarchy/rasklad.layout`, поэтому
  обновляется вместе с пакетом. Он сам спрашивает Fcitx (клон стандартного
  виджета брал раскладку из общего индикатора Omarchy и после перезапуска Fcitx
  застревал на `EN`). Владелец подтвердил: значок появился и меняется. Откат —
  вернуть `"id": "omarchy.keyboard-layout"` в `~/.config/omarchy/shell.json`.
  Миграция Omarchy может вернуть стандартный значок рядом; убрать его можно
  командой `omarchy bar`.
- **Двойной Alt.** Правило Hyprland, подключённое в `~/.config/hypr/bindings.lua`
  строкой `dofile`, которая проверяет, что файл пакета существует (после
  удаления пакета Hyprland не выдаёт ошибку). Только левый Alt: правый Alt
  в Omarchy — запись диктовки (Superwhisper). Владелец подтвердил, что работает.
- **Hyprland.** В `~/.config/hypr/input.lua` добавлен блок: `kb_layout = "us"`,
  без `grp:alts_toggle`. Раскладку переключает только Fcitx. `omarchy refresh
  hyprland` сотрёт и этот блок, и строку `dofile`.
- **Откат.** Убрать блок из `input.lua` и строку `dofile` из `bindings.lua`,
  вернуть id виджета, в Fcitx вернуть прежнюю группу и горячие клавиши
  (`fcitx5-configtool`), затем `hyprctl reload; fcitx5 -rd`. Пакет удаляется
  так: `sudo pacman -R rasklad-fcitx5`. Резервные копии от настройки
  2026-11-22/23 удалены по просьбе владельца после проверки.

- **Состояние и пауза (SYS-248, 0.5.4).** Аддон отдаёт только для чтения
  `fcitx://config/addon/rasklad/status`: `ProfileReady` (профиль прошёл проверку)
  и `AutoCorrect` (копия настройки). Это два флага, текста там нет, на диск они не
  пишутся. Виджет показывает паузу бледным значком, выключение — `EN!`/`RU!`.
  Средний клик ставит на паузу частичным `SetConfig` только с `AutoCorrect`.
  Окно настроек показывает предупреждение, если профиль не прошёл проверку.

## Не сделано / не проверено

- **Нет отмены** после исправления по знаку или Enter. Enter отправляет уже
  исправленное слово.
- **Двойной Alt** (0.5.1) ловит Hyprland (`packaging/hyprland/double-alt.lua`),
  а не аддон: в Slack после первого Alt фокус уходит в меню, и Fcitx второго
  нажатия не видел (замер на хосте 2026-11-23: ни одного переключения в Slack).
  Alt не перехватывается: меню Slack мигает. Alt, буква и снова Alt быстрее
  400 мс тоже переключат раскладку. В закрытом стенде (Sway) правило Hyprland
  не проверить: там тот же `rasklad-layout-toggle` запускается напрямую.
- **Словари и модель** — локальная сборка; при обновлении `hunspell` нужна
  пересборка.
- **Настройки из двух окон сразу.** Rasklad перечитывает настройки перед каждым
  изменением, но у Fcitx нет атомарной записи: если `fcitx5-configtool` сохранит
  что-то в те же миллисекунды, одно из изменений может потеряться. Если диск
  переполнен, Fcitx может сообщить об успешной записи (ошибка самого Fcitx).
