# Направление интерфейса

Пожелание владельца: интерфейс и философия должны быть близки Omarchy.

- Одно компактное окно и одна понятная задача: исправить раскладку текста.
- Тёмный фон, моноширинный системный шрифт с доступным fallback, чёткая
  типографика, сдержанные разделители и минимум декоративных элементов.
- Единственный акцент читается из текущей темы Omarchy только для чтения;
  достаточный контраст и отчётливо видимый keyboard focus.
- Исходник и результат рядом при достаточной ширине, понятный порядок фокуса.
- Основные действия доступны с клавиатуры; сочетания видны в справке.
  Обычные символы, включая Q, ? и пробел, в редакторе остаются вводом текста.
- Результат всегда предварительный, пока человек не нажал Apply. Copy явно
  обозначает, какой текст попадёт в clipboard. Изменение направления не меняет
  исходник. Старая Undo Apply не затирает новую редакцию; у массовой правки своя одноуровневая отмена.
- Никаких dashboard, onboarding, декоративных графиков, счётчиков продуктивности,
  постоянных всплывающих подсказок или искусственных процентов уверенности.
- Язык следует Omarchy; EN/RU переводятся полностью, длинные строки проверяются.
- Установка, launcher entry, глобальные shortcuts и автозапуск не входят в этот
  этап. UI следует окружению, не перенастраивает его.
