# rasklad

Локальное исправление неверной русской/английской раскладки для Omarchy и Hyprland.

Пример: `ghbdtn` → `привет`.

Статус: планирование. Рабочего приложения пока нет.

[Разведка аналогов](docs/OPEN_SOURCE_REVIEW.md) · [Агенты и инструменты](docs/AGENT_SETUP.md) · [Границы безопасности](SECURITY.md)

## План

1. Проверить ввод, фокус и замену текста в Wayland.
2. Реализовать преобразование ru/en и ручные жесты с отменой.
3. Добавить консервативное автоисправление и исключения.
4. Создать окно настроек в стиле Omarchy.
5. Проверить реальные приложения и собрать Arch-пакет.

Стек: C++, Qt Quick, qmake6. Решение о механизме ввода принимается после исследования.

## Управление проектом

Задачи и критерии приёмки ведём в Linear. Ветки называем `SYS-номер/краткое-описание`, идентификатор указываем в коммитах и PR. Завершаем задачи после проверки критериев приёмки.

Набранный текст не отправляется в сеть и не сохраняется в логах. Доступ к устройствам, защита парольных полей и поведение при смене фокуса должны быть проверены до системного автоисправления.

Лицензия будет выбрана перед публичным распространением.
